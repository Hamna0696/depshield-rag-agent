# DepShield AI — RAG Proposal Advisor Agent

An intelligent Retrieval-Augmented Generation (RAG) agent built with **LangChain v1 (`create_agent`)**, **Google Gemini (`gemini-3.5-flash-lite`)**, and **LangGraph (`InMemorySaver`)** to query, analyze, and take advisor meeting notes from the **DepShield AI Final Year Project (FYP) Proposal**.

## Features
- **Document Indexing Pipeline:** Loads `depshield_proposal.pdf` using `PyPDFLoader`, splits text with `RecursiveCharacterTextSplitter`, and indexes embeddings (`models/gemini-embedding-001`) into an `InMemoryVectorStore`.
- **Grounded Answers with Page Citations:** Answers questions strictly from the proposal and cites exact page numbers (e.g., `(page 5)`).
- **Custom Topic-Specific Tool (`save_advisor_note`):** Saves structured summaries and action items from the proposal directly into `advisor_notes.md` with timestamps for FYP supervisory meetings.
- **Conversation Memory:** Uses `InMemorySaver` with `thread_id` persistence to handle multi-turn follow-up questions accurately.

## Repository Contents
- `DepShield_AI_RAG_Agent.ipynb` — Main Google Colab notebook containing the RAG pipeline, custom tool, memory demo, and 10-question test suite.
- `depshield_proposal.pdf` — Source FYP proposal document used for indexing and Q&A.
- `advisor_notes.md` — Sample markdown output generated by the `save_advisor_note` custom tool.
- `README.md` — Project overview and setup instructions.

## How to Run (Google Colab)
1. Open `DepShield_AI_RAG_Agent.ipynb` in Google Colab.
2. Upload `depshield_proposal.pdf` into the Colab session files directory.
3. Open **Secrets** (`🔑` icon on the left sidebar), add a secret named `GEMINI_API_KEY` with your Google Gemini API key, and enable **Notebook access**.
4. Run all cells sequentially to build the vector store, test multi-turn conversation memory, and run the 10 evaluation questions.
